# Retired skills

Kept for reference and one-off use. Not in `skills/sets/global.txt`, not
validated, and not installed by `scripts/link-global.sh`.

- `manuscript-markdown`: DOCX ↔ Markdown roundtrip with the Manuscript Markdown
  CLI. Use only when a user explicitly asks to convert.
- `manuscript-collab`: CriticMarkup agent comments for Markdown drafts.

Manuscripts are now edited directly in Word with tracked changes; see
`skills/manuscript-writing/word-documents.md`. To restore a skill, move it back
to `skills/` and add it to `skills/sets/global.txt` and `validate-skills.sh`.
