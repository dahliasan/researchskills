# Mode: response-to-reviewers

## Steps

1. Read the **actual** reviewer or coauthor comments, manuscript passages,
   nearby paragraphs and references. Inventory every independent request with
   an ID and manuscript location.
2. Classify each point: evidence/analysis, wording, framing, structure, venue
   compliance, or out of scope. Decide agree / clarify / disagree from evidence,
   not a default to agreement.
3. **Extract every paper cited in each comment**, including all references
   within grouped citations. Check each material source claim independently
   with [fact-check](../../fact-check/SKILL.md): examine original full-text
   Methods/Results/tables/figures when available, record evidence locators,
   and identify unavailable papers explicitly. A comment or abstract does
   not verify the source.
4. Check the paper's existing references and actual project outputs before
   accepting a reviewer's factual premise. Address material contrary evidence.
5. Apply evidence and conflict gates to proposed changes. Prefer surgical
   edits ([surgical-edit.md](surgical-edit.md)), unless structural changes
   are required ([revise.md](revise.md) or [draft.md](draft.md)).
   Avoid redundant background and unrelated rewriting.
6. Map each comment to assessment and source evidence, exact manuscript
   locus, local edit or rationale for no change, and concise response.
   Load [scaffolding.md](../scaffolding.md) before editing Methods/Results.
7. Verify changed factual claims and newly introduced citations. Distinguish
   **proposed** edits from **applied** edits: do not say "we have revised"
   until the actual manuscript was modified. Do not invent analyses; route
   missing work to research-project-ops / analysis owners.

**Done when** every comment has a response, material sources were inspected
or individually identified as unresolved, and the letter claims only work
actually performed.

## Output

1. Response map (comment, assessment/evidence, reply, manuscript location,
   edit or justification, applied/proposed status)
2. Local revised manuscript spans in the author's style
3. Material unresolved sources, [TBC], conflicts, deferred analysis

For large requests, show checked/unverified source totals. Avoid generic
praise, speculative objections and optional micro-edits.
